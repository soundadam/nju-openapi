这是一份**非官方**文档。学校没有发布对应的学生 API 手册。这里记的是南大各网页系统在浏览器里实际打的请求：路径、参数、form 字段、返回信封、字段名。

用途是查功能：某个列表怎么筛、某张详情怎么取、通知从哪拉、字段叫什么。不是网关，也不包一层 SDK。请求就是 curl。

Mintlify 站点负责给人读、给 agent 读。Playground 只展示请求形状（`simple`，关代理），不要从文档页打生产。

接口会变，没有 SLA。不要贴真实学号、成绩、课表、手机号。

## 覆盖范围

分三块。**教务 ehall** 是登录后的 `jwapp` 业务接口；**门户与通知**大多是公开的 CMS / 列表抓取；**校园服务**是另一套带独立鉴权的系统。

### 教务 ehall（需登录）

host 是 `ehallapp.nju.edu.cn`。先过[统一认证](/authserver)拿 `CASTGC`，再按 [ehall 会话](/auth) 建会话。

| --- | --- | --- |
| 成绩查询 | `cjcx` | 课程成绩、四六级、体测、学期代码表 |
| 我的课表 | `wdkb` | 个人课表、当前学期、课程信息、教材 |
| 本-课表查询 | `kcbcx` | 全校开课列表、教学班详情 |

| 免修不免考 | `mtxkbl` | 可申请课程、申请列表、提交申请（**含写操作**）|

## 两种请求形状

**ehall** 几乎都是 POST form。列表筛选 `querySetting` 是 JSON **数组的字符串**，分页 `pageNumber` / `pageSize`，排序 `*order`。成功信封：

```json
{ "code": "0", "datas": { "某个.do的名字": { "totalSize": 1, "rows": [] } } }
```

行字段用教务原名：`KCH`、`KCM`、`XF`、`XNXQDM`。

```bash
curl -sS -X POST 'https://ehallapp.nju.edu.cn/jwapp/sys/cjcx/modules/cjcx/cxxscjd.do' \
  -H 'Cookie: CASTGC=...' \
  --data-urlencode 'querySetting=[...]' \
  --data-urlencode '*order=-XNXQDM,+KCH,+KCXZ' \
  --data-urlencode 'pageNumber=1' \
  --data-urlencode 'pageSize=10'
```

**门户**大多是 CMS：有的返回 JSON 文章列表（WebPlus `generalQuery`、交换生 `moreList`），有的只能抓 `list.htm` 的 HTML 再解析。各页会写清是哪种。

## 认证

- [统一认证](/authserver)：`authserver` 登录、密码 AES、滑块验证码、拿 `CASTGC`。
- [ehall 会话](/auth)：`appShow` → `index` → `changeAppRole`。
- [Web VPN](/webvpn)：校外访问，aTrust 域名改写 + 短信两阶段。

## 读文档

先看认证三页，再进各系统的 OpenAPI 页。行字段和示例值都是编的。抓包日期写在各 yaml 的 `x-captured`。
